Description détaillée

QML : Page de détail et de programmation d'une vanne.

Poussée sur le StackView global depuis PagePrincipale.qml, pour la vanne désignée par window.vanneActive. Propose l'ouverture/ fermeture manuelle, l'activation/désactivation de la programmation, et un formulaire de configuration (programmeForm : début, fréquence, durée) déclenché par "Configurer le programme". Les valeurs modifiées dans le formulaire ne sont envoyées à l'ESP32 qu'au clic sur "Enregistrer" (PageVanneJS.enregistrerProgrammation()).
