Description détaillée

Classe C++ : Encodage / décodage des trames JSON du protocole "Contrôleur d'Arrosage" v1.1 (WebSocket, application Qt/QML <-> ESP32).

Ne connaît pas le transport (WebSocket) : produit et consomme des QByteArray/QJsonObject, à charge de ControleurArrosage de les transmettre via CommunicationESP32. Les méthodes d'extraction (getType(), getCommande(), ...) renvoient une valeur par défaut neutre ('\0' ou 0) si le champ est absent de la trame, plutôt que d'échouer.

Documentation des énumérations membres

◆ CodeErreur

enum ProtocoleArrosageClient::CodeErreur

Codes d'erreur retournés par le boîtier dans une trame d'erreur (§8 du protocole).

Valeurs énumérées
ERREUR_AUCUNE 

Aucune erreur.

ERREUR_VANNE_INEXISTANTE 

L'identifiant de vanne ne correspond à aucune vanne connue du boîtier.

ERREUR_MODE_INVALIDE 

Le mode demandé n'est pas une valeur MODE_* valide.

ERREUR_PROG_INVALIDE 

La programmation demandée est invalide (heure, durée ou fréquence).

ERREUR_RTC_INDISPONIBLE 

Le RTC du boîtier est indisponible.

ERREUR_SQLITE_INDISPONIBLE 

Le stockage persistant du boîtier est indisponible.
