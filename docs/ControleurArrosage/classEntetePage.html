Description détaillée

QML Component : En-tête de page standard : bouton retour + titre.

Factorise le motif "Retour + titre" répété en haut de PageVanne.qml et PageConfiguration.qml. Ne gère pas son propre positionnement (anchors, height) : c'est à la page appelante de les définir selon son contexte (voir les usages).
