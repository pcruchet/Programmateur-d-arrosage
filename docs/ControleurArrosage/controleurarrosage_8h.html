Description détaillée

Orchestrateur central de l'application Qt/QML "Contrôleur d'Arrosage".

Déclare la classe ControleurArrosage, qui joue quatre rôles :

  • modèle de liste pour QML (QAbstractListModel), exposant les objets Vanne aux composants d'interface ;
  • traduction des actions utilisateur (ouverture/fermeture, changement de mode, programmation) en trames du protocole applicatif via ProtocoleArrosageClient ;
  • émission/réception des trames via CommunicationESP32 ;
  • mise à jour des objets Vanne (miroir de l'état réel du boîtier) à partir des réponses et notifications spontanées reçues de l'ESP32, et persistance de la configuration de connexion (adresse IP / port) sur disque.
