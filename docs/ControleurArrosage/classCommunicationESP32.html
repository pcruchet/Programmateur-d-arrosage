Description détaillée

Classe C++ : Encapsule la connexion WebSocket vers le boîtier ESP32.

Gère l'ouverture/fermeture de la connexion, l'émission de messages texte, et un timer périodique (10 s) qui envoie un ping WebSocket tant que la connexion est active, permettant de détecter une coupure silencieuse. Une reconnexion demandée pendant qu'une connexion est déjà active attend la déconnexion effective (onDisconnected()) avant de se relancer.
