Description détaillée

Singleton QML regroupant les constantes visuelles de l'application (couleurs, tailles, espacements).

Remarques
This component is a singleton

Accessible depuis n'importe quel fichier QML du module "ControleurArrosage" sans import explicite (singleton du même module). Objectif : centraliser les valeurs de style pour éviter leur duplication et faciliter une charte graphique cohérente.
