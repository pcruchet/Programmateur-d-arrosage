Description détaillée

QML Component : Motif "icône + libellé en gras", utilisé comme sous-titre de section.

Factorise le couple Text(icone)/Text(titre en gras) répété dans PageVanne.qml et PageConfiguration.qml (Début d'arrosage, Fréquence d'arrosage, Adresse IP du boîtier, ...). Style basé sur Constantes.tailleTitre1/tailleTitre2/couleurAppliTexte.
