Description détaillée

Image logicielle d'une électrovanne, côté application Qt/QML.

Déclare la classe Vanne, objet de données pur exposé à QML (propriétés Q_PROPERTY, énumérations Q_ENUM) représentant l'état connu d'une électrovanne physique pilotée par l'ESP32. Vanne ne communique jamais directement avec l'ESP32 : c'est ControleurArrosage qui met à jour ses propriétés à partir des réponses/notifications reçues via ProtocoleArrosageClient.
