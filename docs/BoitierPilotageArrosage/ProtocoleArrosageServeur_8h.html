Detailed Description

Encodage/décodage des trames JSON du protocole applicatif "Contrôleur d'Arrosage" (WebSocket, ESP32 <-> application Qt/QML).

Toutes les trames partagent la structure générale {"v":<version>,"t":"<type>","c":"<commande>", ...}. Cette classe ne réalise aucune action métier : elle se contente de décoder les requêtes entrantes (decoder()) et de construire les trames JSON de réponse, d'accusé de réception, d'erreur et de notification, à charge pour BoitierPilotageArrosage d'orchestrer leur utilisation.
