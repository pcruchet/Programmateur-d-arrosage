◆ estimerPourcentage()

uint8_t MesureBatteries::estimerPourcentage ( ) const

Estime le niveau de charge du pack à partir de sa seule tension à vide (approximation : ne tient pas compte de la chute de tension en charge/décharge).

Interpole linéairement entre TENSION_PACK_VIDE_V (0 %) et TENSION_PACK_PLEINE_V (100 %), puis borne le résultat.

Returns
Pourcentage estimé (0 à 100).

◆ initialiser()

bool MesureBatteries::initialiser ( )

Initialise la communication I2C avec le capteur et applique la calibration par défaut (plage 32 V / 2 A), largement suffisante pour un pack 3S chargé/déchargé à quelques centaines de mA.

Returns
true si le capteur a été détecté et initialisé.
