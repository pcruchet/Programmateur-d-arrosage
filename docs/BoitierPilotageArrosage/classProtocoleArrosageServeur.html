◆ decoder()

RequeteArrosage ProtocoleArrosageServeur::decoder ( const String &  _message) const

Décode une trame JSON reçue en structure RequeteArrosage.

Décode une trame JSON en RequeteArrosage.

Vérifie la présence des champs obligatoires ("v", "t", "c") et la compatibilité de version avant de considérer la requête comme valide. Les champs optionnels (idVanne, mode, heure, duree, frequence) ne sont renseignés que s'ils sont présents dans la trame reçue.

Parameters
_messageTrame JSON brute reçue du client.
Returns
Structure décodée ; RequeteArrosage::valide vaut false si le parsing JSON a échoué, si un champ obligatoire est absent, ou si la version ne correspond pas à VERSION.

Échoue proprement (valide=false) en cas d'erreur de désérialisation, de champs obligatoires "v"/"t"/"c" absents ou mal typés, ou de version différente de VERSION. Les champs optionnels "i", "m", "h", "d", "f" ne sont recopiés que s'ils sont présents et correctement typés dans le JSON reçu.
